# 实验流程

## 1. 首先利用IP核生成25MHz的时钟，并且使用内嵌的倍频功能输出100MHz，200MHz的时钟，并通过内嵌的分频功能生成一个10MHz的时钟

报告要求：IP 核的配置界面，波形图（100MHz，200MHz，10MHz）


## 2. 接着编写自己的分频模块（使用计数器翻转法），书写testbench：100MHz--》20MHz，10MHz--》1kHz

报告要求：代码（两个代码，testbench，顶层）



## 3. 接着添加约束文件：时钟约束，引脚约束。

报告要求：约束代码


## 4. 接着验证在行为仿真下，是否依然可以实现倍频的功能。

报告要求：波形图（100MHz，20MHz，10MHz，1kHz）



## 5. 接着进行综合，实现和生成bit流并且进行JTAG下载+ILA（或示波器）观察，看板子上是否依然可以实现倍频的功能。

### 5.1 综合，实现和生成bit流
1. 完成综合、实现后，点击 Generate Bitstream 生成比特流文件（.bit）；
2. 用 USB 下载器连接实验箱 JTAG 接口，接通电源（注意单排针方向，勿带电插拔）；
3. 打开 Hardware Manager → Open Target → Auto Connect 连接 FPGA；
4. 右键器件 → Program Device，选择 .bit 文件完成下载；


### 5.2 ILA单元测试


#### ILA使用方法
1. 在 IP Catalog 中搜索并添加 ILA IP，设置采样时钟与探针数量、位宽（Probes）；
2. 在顶层将待观测信号（clk_100M、clk_20M、clk_10M、clk_1k）接入 ILA 探针，采样时钟选用 200MHz；
3. 重新综合、实现并生成比特流，按上板流程下载；
4. 在 Hardware Manager 中设置触发条件（如信号上升沿），点击运行按钮捕获波形。

#### 单元测试要求
分别用 100MHz 与 200MHz 作为 ILA 的采样时钟，观察同一个 10MHz（或 1KHz）信号，截图对比两种设置下的波形差异，并写入实验报告。

核心观察：
- 时间分辨率：200MHz 采样间隔 5ns，100MHz 采样间隔 10ns，对信号边沿的刻画精细程度不同；
- 采样定理：采样时钟频率需高于被测信号频率的 2 倍，恢复的波形才可信；
- 思考题：若用远低于被测信号的时钟采样，会观察到什么现象？（混叠/假频）

注意事项：ILA 探针会占用逻辑与 BRAM 资源，采样深度（Sample Depth）越大占用越多，应按需设置。
